# linux-toolkit
This repository was created to practice and test Bash scripts written from scratch.

## disk-check.sh
Checks the current disk usage and warns if it's above 80% (warning) or 90% (urgent), logging the results with a timestamp.

### Usage
`./disk-check.sh`

### What I learned
Basic Linux and Git commands — I used `awk` because I needed to isolate a specific column from the output, combined with pipes to extract the value, and implemented log file generation.
I also practiced resolving merge conflicts to combine two branches into one, keeping the most relevant features from each.
